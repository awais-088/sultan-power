# Sultan Power

A responsive business website for **Sultan Brothers Power Engineering Repairing and Parts**.

## Tech stack
- Next.js App Router + TypeScript
- React 19
- Framer Motion
- Lucide React
- Custom responsive CSS

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm start
```

## Business configuration

- Map coordinates from the supplied listing: `30.966625, 71.0653971`

The contact form builds a WhatsApp message and opens it in a new tab. It does not store enquiries on a server.

## Deploy to Vercel
1. Push this repository to GitHub.
2. Import the repository at https://vercel.com/new.
3. Keep the detected Next.js framework settings and deploy.
4. Set the project name to `sultan-power` if the slug is available.

## Before launch
Replace the CSS-built illustrative engine visual with real photos of the shop, generators and repair work when available. Confirm the map pin and business details with the owner. Brand names are enquiry references; confirm actual stock and authorized service status before making stronger claims.
